Monday 23 November 2026 — Mid-Day Edition: a broadsheet front page that sums up 23 November's world news in one image. 36 stories across 7 regions — COP31 collapses with no climate deal in Antalya, Ukrainian sea drones sink the Russian warship Merkury off Libya, a Russian drone strike kills 11 in Dymer — with a six-number strip, a UTC timeline, 15 code-drawn illustrated panels, a numbered world map, and a DATE CHECK naming what was deliberately left out. All text is rendered in smooth, normal writing — a fresh hand-built vector font rasterized with anti-aliasing, no dot-matrix letterforms anywhere. Every illustration is drawn in code; the whole page is rendered by `main.ts` (Node 22, standard library only, no network) into a deterministic 1024×1024 PNG.

## Run it

```sh
node main.ts
```

This writes `/output/entry.png` (1024×1024, deterministic — two runs produce identical bytes).
